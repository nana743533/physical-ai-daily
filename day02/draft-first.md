## はじめに

強化学習を14日で一通りやる連載の2日目です。昨日は、倒立振子（CartPole）をコイン投げで操作したら平均 22.2 ステップで倒れる、という数字を出しました。

今日は、その同じ 1,000 エピソードを一切動かし直さずに、「このエピソードにどれだけの価値があったか」を数え直します。数え方には割引率という1つのつまみがあって、それを 0.9 から 0.99 に変えるだけで、同じエピソードの価値が 2.3 倍になりました。なぜそうなるのか、そしてそれが学習にどう関係するのかを書きます。

実験コードと結果は [GitHub](https://github.com/nana743533/physical-ai-daily/tree/master/day02) に置いています。

## 収益、割引率、価値関数

昨日の4つの言葉（状態・行動・報酬・方策）に、今日は3つ足します。

**収益**（return）は、ある時点から先にもらう報酬の合計です。時刻 t からの収益 G を、報酬 r を使って次のように書きます。

```
G_t = r_t + γ r_{t+1} + γ^2 r_{t+2} + ...
```

γ（ガンマ）が**割引率**で、0 以上 1 以下の数です。1 ステップ先の報酬は γ 倍、2 ステップ先は γ の 2 乗倍と、遠い将来ほど軽く数えます。今日の 100 円は来年の 100 円より価値がある、という利子の考え方と同じです。

なぜ割り引くのかは、理由が2つあります。1つは、終わりのないタスクで報酬の合計が無限大にならないようにするためです。もう1つは、遠い将来の報酬ほど「本当にもらえるか」が不確かなので、近い報酬を重く見た方が学習が安定しやすいからです。

割引率には、覚えておくと便利な読み方があります。1 ステップごとに報酬 1 が永遠に続くとき、収益は 1 / (1 - γ) に収束します。γ = 0.9 なら 10、γ = 0.99 なら 100 です。つまり γ は「だいたい何ステップ先まで見ているか」を決めていて、0.9 は 10 ステップ先、0.99 は 100 ステップ先までしか実質的に見ていません。

**価値関数**（value function）は、ある状態から始めて、その方策に従ったときの収益の期待値です。状態 s の価値を V(s) と書きます。1 回のエピソードの収益はたまたまの値ですが、同じ状態から何回も始めて平均を取れば、その状態の価値に近づきます。

今日計算する「1,000 エピソードの収益の平均」は、CartPole の初期状態の、ランダム方策のもとでの価値 V(初期状態) の推定値です。方策を良くすればこの値は上がります。明日以降の学習は、この価値を手がかりにして方策を直していく話になります。

## やったこと

CartPole は 1 ステップ耐えるごとに報酬が 1 なので、長さ L のエピソードの収益は等比数列の和で閉じた形になります。

```
G = 1 + γ + γ^2 + ... + γ^(L-1) = (1 - γ^L) / (1 - γ)
```

γ = 1.0 のときは G = L です。昨日保存した 1,000 本のエピソード長から、γ = 0.9、0.99、1.0 の3通りで収益を計算しました。

```python
import json
import numpy as np

lengths = np.array(json.load(open("day01/result.json"))["lengths"])

def discounted_return(length, gamma):
    length = np.asarray(length, dtype=float)
    if gamma == 1.0:
        return length
    return (1.0 - gamma ** length) / (1.0 - gamma)

for gamma in [0.9, 0.99, 1.0]:
    G = discounted_return(lengths, gamma)
    print(gamma, G.mean(), G.max(), discounted_return(500, gamma))
```

最後の `discounted_return(500, gamma)` は、満点の 500 ステップ耐えたときの収益です。今日の平均がその何割かを見るために出しました。

## 結果

同じ 1,000 エピソードの収益の平均は、γ = 0.9 で **8.5**、γ = 0.99 で **19.5**、γ = 1.0 で **22.2** でした。0.9 から 0.99 に変えると 2.3 倍です。

| γ | 平均 | 中央値 | 最小 | 最大 | 500 ステップ耐えたときの収益 | 平均はその何割か |
|---|---|---|---|---|---|---|
| 0.9 | 8.5 | 8.6 | 5.7 | 10.0 | 10.0 | 85% |
| 0.99 | 19.5 | 17.4 | 7.7 | 53.4 | 99.3 | 20% |
| 1.0 | 22.2 | 19.0 | 8.0 | 76.0 | 500.0 | 4.4% |

![同じ 1,000 エピソードの収益を、割引率だけ変えて数え直した分布](https://raw.githubusercontent.com/nana743533/physical-ai-daily/master/day02/returns_hist.png)

分布の形が γ でまったく違います。γ = 1.0 では昨日の分布そのままで、右に長い裾を引いています。γ = 0.99 では裾が縮んで最大が 53 になります。γ = 0.9 では分布が 10 の壁に押しつけられて、左右が逆になったような形になりました。

一番大きいのは右端の列です。γ = 0.9 だと、コイン投げで操作しただけの今日のエピソードが、満点の 85% の価値を持っていることになります。γ = 1.0 なら 4.4% です。

![エピソードの長さと収益の関係](https://raw.githubusercontent.com/nana743533/physical-ai-daily/master/day02/return_vs_length.png)

長さと収益の関係を描くと理由が見えます。γ = 0.9 の曲線は 20 ステップあたりで 10 に張りつきます。30 ステップ耐えたエピソードの収益は 9.58、最長の 76 ステップでも 9.997 で、差は 0.4 しかありません。500 ステップ耐えても 10.0 です。γ = 0.9 のもとでは、30 ステップと 500 ステップはほとんど同じ価値です。

γ = 0.99 では同じ 30 ステップと 76 ステップが 26.0 と 53.4 で、2 倍の差がつきます。

## 今日分かったこと

- 収益は将来の報酬を γ 倍ずつ割り引いて足したもので、1 / (1 - γ) がおおよその見通しの長さになる。0.9 は 10 ステップ先、0.99 は 100 ステップ先
- 同じ 1,000 エピソードでも、γ を 0.9 から 0.99 にすると平均の収益が 8.5 から 19.5 へ 2.3 倍になる。数字そのものに意味はなく、γ を決めて初めて比べられる
- γ = 0.9 の CartPole では、30 ステップ耐えるのと 500 ステップ耐えるのが 9.58 と 10.0 でほぼ区別がつかない。満点の 500 まで伸ばしたいなら、500 ステップ先の差が収益に残る γ = 0.99 のような値が要る。CartPole の実装例で γ = 0.99 が多いのはこのためだと理解した。学習で本当に差が出るかは、Q 学習をやる4日目以降に確かめる
- 1,000 回の収益の平均は、ランダム方策のもとでの初期状態の価値 V の推定値。方策を良くするとは、この値を上げること

明日は、環境のルール（どの状態でどの行動を取ると、どの状態にどの確率で移るか）が全部分かっているときの話です。その場合は試行錯誤の学習をしなくても、ベルマン方程式を繰り返し解くだけで最適な方策が求まります。氷の上を滑る FrozenLake を価値反復で解いて、成功率を出します。
