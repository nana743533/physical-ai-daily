## 使う道具

**Gymnasium** は、強化学習の練習問題を同じ書き方で動かせる Python のライブラリです。`env.reset()` で問題を初期化し、`env.step(行動)` で1手進めると、新しい状態と報酬が返ってきます。どの問題でもこの2つの関数で動かせるので、問題を差し替えて比べるのが楽です。

**CartPole-v1** は Gymnasium に入っている練習問題の1つで、この記事で扱う倒立振子です。名前の末尾の v1 はバージョンで、v0 は 200 ステップで打ち切り、v1 は 500 ステップで打ち切りという違いがあります。

## 倒立振子（CartPole）とは何か

台車の上に棒が立っていて、棒が倒れないように台車を左右に動かす問題です。1ステップごとに「左に押す」か「右に押す」かを選びます。棒が 12 度以上傾くか、台車が中央から 2.4 以上離れたらそこで終わりです。500 ステップ耐えると打ち切りで、それが満点です。

1ステップ耐えるごとに報酬が 1 もらえるので、「何ステップ耐えたか」がそのまま得点です。

## 強化学習が解く問題を、この振子で定義する

強化学習では、問題を状態・行動・報酬・方策の4つで定めます。CartPole に当てはめると次のようになります。

- **状態**（state）: いま何が起きているか。台車の位置、台車の速度、棒の角度、棒の角速度の4つの数です
- **行動**（action）: 自分が選べること。左に押す（0）か右に押す（1）の2択です
- **報酬**（reward）: 行動の直後にもらえる点数。1ステップ耐えるごとに 1 です
- **方策**（policy）: 状態を見て行動を決めるルール。これを学習で良くしていくのが強化学習です

この記事の方策は、状態を見ずにコイン投げで左右を決めるランダムな方策です。学習を何もしていない状態の成績を先に測っておくと、あとで学習を入れたときの伸びが分かります。

教師あり学習と違うのは、正解の行動を誰も教えてくれないことです。「この状態では右が正解」というラベルはなく、何ステップか後に「倒れた」という結果だけが返ってきます。どの行動が良かったのかを結果から逆算する必要があって、それが強化学習の難しさの中心です。

## やったこと

`CartPole-v1` を 1,000 エピソード動かしました。エピソードとは、初期化してから終わるまでの1回分のことです。各ステップの行動は `numpy` の乱数で 0 か 1 を選んでいます。

```python
import gymnasium as gym
import numpy as np

env = gym.make("CartPole-v1")      # 倒立振子の環境を用意する
rng = np.random.default_rng(0)     # 乱数の種を固定する（再現できるように）
lengths = []                       # 各エピソードで何ステップ耐えたかを入れる
for ep in range(1000):
    obs, info = env.reset(seed=ep)  # 棒をほぼ直立の状態に戻す
    steps = 0
    while True:
        action = int(rng.integers(env.action_space.n))  # 0 か 1 をコイン投げで選ぶ
        obs, reward, terminated, truncated, info = env.step(action)  # 1 手進める
        steps += 1
        if terminated or truncated:  # 倒れたか、500 ステップに達したら終わり
            break
    lengths.append(steps)
```

`env.step()` が返す `terminated` と `truncated` は、どちらもエピソードが終わったことを示す真偽値ですが、意味が違います。`terminated` は問題のルール上の終わり（棒が倒れた、台車がはみ出た）で、`truncated` は時間切れによる打ち切り（500 ステップに達した）です。この区別は、将来の報酬を見積もるときに「この先まだ続いたはずか」を判断するために必要になります。この実験では `truncated` は一度も立ちませんでした。

## 結果

1,000 回の平均は **22.2 ステップ**でした。

| 項目 | 値 |
|---|---|
| 平均 | 22.2 ステップ |
| 中央値 | 19 ステップ |
| 最短 | 8 ステップ |
| 最長 | 76 ステップ |
| 上位 10% の境目 | 38 ステップ |
| 100 ステップ以上耐えた回数 | 0 回 |

![倒れるまでのステップ数の分布](https://raw.githubusercontent.com/nana743533/physical-ai-daily/master/day01/hist.png)

分布は右に長い裾を引いています。10〜20 ステップに半分以上が集まっていて、運よく 50 ステップを超えるのが 1,000 回のうち 50 回ほど、最長でも 76 ステップでした。コイン投げでは 100 ステップにも届きません。

8 ステップより短いエピソードが無いのは、初期状態が「ほぼ直立、ほぼ静止」から始まるので、どう押しても 8 ステップ分は倒れきらないからです。

## 分かったこと

- 学習なしの CartPole は平均 22 ステップ、最長でも 76 ステップで倒れる。満点の 500 とは 20 倍以上の差がある
- 強化学習の問題は、状態・行動・報酬・方策の4つで定める。学習で変えるのは方策だけ
- 正解の行動は教えてもらえず、倒れたという結果だけが返ってくる。結果からどの行動が良かったかを逆算するのが、この先の記事でやることの中身
