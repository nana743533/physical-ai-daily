## はじめに

Physical AI、つまり画面の外で物を動かす AI に興味が出てきたので、その土台になる強化学習を14日で一通りやることにしました。毎日1つの概念を取り上げて、その日に自分で動かした結果の数字と一緒に書きます。14日目には、物理シミュレータ MuJoCo の2リンクのロボットアームを PPO で目標位置まで動かすところまで行く予定です。

1日目の今日は、学習を一切せずに、倒立振子をコイン投げで操作したら何ステップで倒れるのかを数えました。この数字が、明日からの学習がどれだけ効いたかを測る物差しになります。

実験コードと結果は [GitHub](https://github.com/nana743533/physical-ai-daily/tree/master/day01) に置いています。

## 倒立振子（CartPole）とは何か

台車の上に棒が立っていて、棒が倒れないように台車を左右に動かす問題です。Gymnasium の `CartPole-v1` では、1ステップごとに「左に押す」か「右に押す」かを選びます。棒が 12 度以上傾くか、台車が中央から 2.4 以上離れたらそこで終わりです。500 ステップ耐えると打ち切りで、それが満点です。

1ステップ耐えるごとに報酬が 1 もらえるので、「何ステップ耐えたか」がそのまま得点です。

## 強化学習が解く問題を、この振子で定義する

強化学習の問題はいつも同じ形をしています。4つの言葉で書けます。

- **状態**（state）: いま何が起きているか。CartPole では、台車の位置、台車の速度、棒の角度、棒の角速度の4つの数です
- **行動**（action）: 自分が選べること。左に押す（0）か右に押す（1）の2択です
- **報酬**（reward）: 行動の直後にもらえる点数。1ステップ耐えるごとに 1 です
- **方策**（policy）: 状態を見て行動を決めるルール。これを学習で良くしていくのが強化学習です

今日の方策は「状態を見ない。コイン投げで左右を決める」です。これが一番弱い方策なので、ここから始めます。

教師あり学習と違うのは、正解の行動を誰も教えてくれないことです。「この状態では右が正解」というラベルはなく、何ステップか後に「倒れた」という結果だけが返ってきます。どの行動が良かったのかを結果から逆算する必要があって、それが強化学習の難しさの中心です。

## やったこと

`CartPole-v1` を 1,000 エピソード動かしました。各ステップの行動は `numpy` の乱数で 0 か 1 を選んでいます。

```python
import gymnasium as gym
import numpy as np

env = gym.make("CartPole-v1")
rng = np.random.default_rng(0)
lengths = []
for ep in range(1000):
    obs, info = env.reset(seed=ep)
    steps = 0
    while True:
        action = int(rng.integers(env.action_space.n))  # 左右をコイン投げで選ぶ
        obs, reward, terminated, truncated, info = env.step(action)
        steps += 1
        if terminated or truncated:
            break
    lengths.append(steps)
```

`terminated` が倒れたとき、`truncated` が 500 ステップの打ち切りです。今日は `truncated` は一度も立ちませんでした。

## 結果

1,000 回の平均は **22.2 ステップ**でした。

| 項目 | 値 |
|---|---|
| 平均 | 22.2 ステップ |
| 中央値 | 19 ステップ |
| 最短 | 8 ステップ |
| 最長 | 76 ステップ |
| 上位 10% の境目 | 38 ステップ |
| 100 ステップ以上耐えた回数 | 0 回 |

![倒れるまでのステップ数の分布](https://raw.githubusercontent.com/nana743533/physical-ai-daily/master/day01/hist.png)

分布は右に長い裾を引いています。10〜20 ステップに半分以上が集まっていて、運よく 50 ステップを超えるのが 1,000 回のうち 50 回ほど、最長でも 76 ステップでした。コイン投げでは 100 ステップにも届きません。

8 ステップより短いエピソードが無いのは、初期状態が「ほぼ直立、ほぼ静止」から始まるので、どう押しても 8 ステップ分は倒れきらないからです。

## 今日分かったこと

- 学習なしの CartPole は平均 22 ステップ、最長でも 76 ステップで倒れる。満点の 500 とは 20 倍以上の差がある
- 強化学習の問題は、状態・行動・報酬・方策の4つで書ける。学習で変えるのは方策だけ
- 正解の行動は教えてもらえず、倒れたという結果だけが返ってくる。結果からどの行動が良かったかを逆算するのが、明日からやることの中身

明日は、「倒れるまでの報酬の合計」をどう数えるかの話です。将来の報酬をどれだけ割り引くか（割引率）を 0.9 から 0.99 に変えると、今日の同じ 1,000 エピソードの価値がどう変わるかを計算します。
