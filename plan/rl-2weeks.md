# 第1期 強化学習の2週間（14本）の計画

最終更新: 2026-10-19

強化学習を14日で一通りやり、14日目に MuJoCo の2リンクアーム（Reacher）が PPO で目標に届くところまでを書きます。毎日「1つの概念」と「その日に自分で動かした結果の数字」を1本にします。タイトルの中の〇は、実験を回してから実際の数字に差し替えます。

道具は Gymnasium、MuJoCo、Stable-Baselines3、PyTorch で、費用はかかりません。前半（1〜7日目）は倒立振子（CartPole）で表の Q 学習から DQN まで、後半（8〜14日目）は連続行動の Pendulum とアーム（Reacher）で方策勾配から PPO までです。

## 進め方

- 投稿の前日に実験を回し、当日の朝に書いて出す。1日分の貯金を常に持つ
- 実験のコードと結果（数字・図・動画）はこのリポジトリに日ごとのフォルダ（`dayNN/`）で置き、記事からリンクする。図は GitHub の raw URL で貼る
- タイトルの数字は実験後に入れる。出なかった数字は書かない
- 各日の叩き台は保存して触らず、公開版との差分を2週目の終わりに見て、毎回直した所をこのファイルの下に足す

## 記事の書き方の決まり

- 1本の形は「1つの概念 ＋ その日に自分で動かした数字」。概念だけの記事は出さない
- 数字は実験で出たものだけを書く
- 構成は「はじめに → 概念 → やったこと → 結果 → 今日分かったこと → 明日の予告 → 検証環境」でそろえる
- 記事の先頭にこのリポジトリの該当フォルダ、末尾に検証環境（バージョン・OS・実行日）を書く
- ダッシュ（—）、ダブルクォート、「効く」は使わない。保存前に検索して 0 件にする
- 手元で確かめた範囲より先のことを言い切らない
